Pourquoi ces deux objectifs ?

Un sol perméable laisse l'eau de pluie s'infiltrer : la cour inonde moins et reste plus fraîche. L'ombre des arbres fait baisser la température en été. La Ville vise au moins 40 % pour chacun.

    Comment ça marche

    Ajouter

    Touchez un élément dans la liste : il apparaît sur le plan et sa fiche s'ouvre (conseils, réglages). Pour un sol (copeaux, herbe…), touchez-le puis peignez sur le plan. Le bouton Recommencer remet le plan de départ, et on peut annuler juste après.

    Modifier

    Touchez un élément : des poignées apparaissent autour. Glissez-le pour le déplacer, la poignée ronde du haut le fait tourner, les coins l'agrandissent, les côtés l'allongent. Les boutons juste à côté le dupliquent ou le suppriment.

    Se déplacer sur le plan

    Pincez à deux doigts pour zoomer, glissez le fond pour déplacer le plan. En mode pinceau, utilisez deux doigts.

    Molette pour zoomer, glissez le fond pour déplacer le plan. En mode pinceau : clic droit ou barre d'espace pour déplacer.

    Le bouton ramène la vue d'ensemble.

    Repères

    Quadrillage : 5 m. Les arbres verts sont conservés. Les jeux gris (toboggan, bac à sable, marquages) existent aujourd'hui : vous pouvez les garder, les déplacer ou les supprimer.

    Clavier

    Tab pour atteindre un élément, flèches pour le déplacer (Maj : 2 m), R pour tourner, + et − pour la taille (Alt : largeur), Suppr pour l'effacer, Ctrl+Z pour annuler.
