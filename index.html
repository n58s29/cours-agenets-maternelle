    3. Je partage

    Plan schématique : positions et surfaces indicatives, le paysagiste conçoit le projet final. Rien n'est envoyé : tout reste dans votre navigateur.

    Comment ça marche

    • Choisissez un élément en bas (ou à gauche sur ordinateur) : il apparaît au centre du plan.
    • Glissez-le pour le déplacer. Tirez un côté pour changer sa longueur ou sa largeur, un coin pour l'agrandir. ↻ le fait pivoter, ✕ le supprime. Des boutons équivalents existent dans la barre de l'élément sélectionné.
    • Pour un sol : choisissez-le, maintenez le doigt ou le clic et peignez. La gomme efface.
    • Plan : pincez à deux doigts pour zoomer, glissez le fond pour le déplacer. Sur ordinateur : molette pour zoomer, glisser le fond pour déplacer. Le bouton ⤢ ramène la vue d'ensemble.
    • Les arbres sont conservés. Le bac à sable, le toboggan et les jeux actuels (en gris) peuvent être supprimés.
    • Clavier : Tab pour atteindre un élément, flèches pour le déplacer (Maj = 2 m), Suppr pour l'effacer.
    • Quadrillage : 5 m. Objectifs de la Ville : 40 % de sol perméable et 40 % d'ombre.
